# Aaavatar

Native macOS app that processes portrait photos consistently: remove the
background, auto-align on the face, enhance, style, and export in one click to
LinkedIn / Slack / email / banners.

**[Download Aaavatar](https://github.com/Square-One-Official/Avatar/releases/latest/download/Aaavatar.dmg)** ·
**[aaavatar.nl](https://aaavatar.nl)** ·
[Privacy policy](https://aaavatar.nl/privacy-policy)

Requires macOS 14 or later.

## About this repository

This repository hosts the **release downloads** for Aaavatar. The application
source code is private.

Published releases here are the canonical download location and are referenced
by the app's built-in updater — please do not rely on mirrors.
