# Aaavatar 2.0

Aaavatar 2.0 is a new app, built from the ground up: a new design, a real editor, and every AI edit routed through your account and credits instead of a single "magic cutout".

## What's new

- **New home & library** — folders, multi-select, batch actions and a board view for whole sets.
- **Studio editor** — framing, adjust (exposure, temperature, tint), enhance tiles, backgrounds (colour, image, Unsplash, AI-generated), effects, and a canvas you can zoom and pan.
- **Effects 2.0** — nine curated styles plus your own custom effects, with die-cut sticker and head-only variants rendered on-device.
- **Remove background on-device** — Vision by default, a downloadable high-quality model for tricky edges. No credits, no upload.
- **Cloud edits with credits** — Fill in body, Boost resolution, Colorize, Apply effect and AI backgrounds. Starter plan is free; Pro and top-ups via Settings → Billing.
- **Share** — one-click export for LinkedIn, Slack, e-mail and social previews, in the shape and size each platform expects.
- **Sign in with e-mail** — a one-time code, no password, no Google prompt.

## Coming from Aaavatar 1?

**Export a backup in Aaavatar 1 first.** Aaavatar 2.0 has the same app name, so dragging it into Applications replaces the old version. Your old library stays on disk, but the app that can export it is gone once replaced. Then in the new Aaavatar open **Settings → Preferences → Import from Aaavatar 1** and pick the backup: cutouts, names and dates come along. Need the old version back? It stays available as [v1.2.1](https://github.com/Square-One-Official/Avatar/releases/tag/v1.2.1).

## Requirements

macOS 14 Sonoma or newer. Updates arrive automatically via Sparkle.
