# Aaavatar 2.0.1

A small update for everyone coming from Aaavatar 1: your old library can now be imported straight from this Mac, no backup file needed.

## What's new

- **Import from Aaavatar 1 on this Mac** — Settings → Preferences → Migration → *Import from this Mac* finds the library the previous version left on this Mac and brings over your portraits: cutouts, names, dates and the original photos (a backup file doesn't contain those). The first-use screen offers the same link. macOS may ask once whether Aaavatar may access data from other apps; choose Allow.
- **Backup import stays** — *Import from a backup file* still works for moving a library between Macs. Importing twice never duplicates a portrait.

## Requirements

macOS 14 Sonoma or newer. Updates arrive automatically via Sparkle.
